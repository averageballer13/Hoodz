Hoodz deployer

Deploys the Hoodz contract stack from the dev wallet, one transaction at a time.

This deploys to Robinhood Chain mainnet with real ETH. Run the pre-flight first: it estimates every contract against the live chain, so anything that would revert fails for free instead of costing a deployment. Nothing is sent until you press Deploy.

One transaction per contract. If one fails, the rest stop, progress is saved, and pressing Deploy again resumes from that contract — you never redeploy what already landed.

It gives you addresses, not a working protocol. Roles and permissions are separate: the governor handover, lockVaultToGuard and the treasury permission queue all still have to be run afterwards — see docs/DEPLOYMENT.md. Deploying on testnet once first is cheap insurance; flip the selector above.
