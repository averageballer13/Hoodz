Hoodz deployer

Deploys the Hoodz contract stack from the dev wallet, one transaction at a time.

Use this for testnet. For a mainnet deployment of a treasury protocol, run forge script script/Deploy.s.sol:Deploy instead: it simulates the whole sequence before broadcasting, wires every role atomically, and verifies on Blockscout in the same command. This page sends one transaction per contract, so a failure halfway leaves a partially deployed system — recoverable (progress is saved and it resumes where it stopped) but messy.

It also does not wire roles or permissions. It gives you addresses. The role handover, lockVaultToGuard and the treasury permission queue still have to be run afterwards — see docs/DEPLOYMENT.md.
